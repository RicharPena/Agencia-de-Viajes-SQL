README AGENCIA DE VIAJES SQL

Buenas y bienvenidos a mi proyecto llamado "Agencia de viajes" contiene en su nombre "SQL" debido a que contiene una base de datos. Ahora bien, para poder instalar la base de datos es necesario tener distintas cosas,
elementos, archivos instalados para que la aplicación pueda servir:

1) Como ya pudieron darse cuenta, el proyecto está escrito en JAVA. Como tal no tiene un ejecutable propio, por lo que se deberá instalar el JDK 21 junto con Apache Netbeans.
2) Se deberá instalar my-sql-connector-j-9.1.0.jar debido a que es necesario para manejar la base de datos. Posteriormente añadirla a la carpeta librerias e indicar a Netbeans donde se encuentra el archivo.
3) Tener instalado MySQL y ejecutar el archivo llamado "Agencia de viajes (base de datos REAL).sql"
4) Al principio de la aplicación se le pedirá que ingrese una contraseña. Esa contraseña es la que usted le haya asignado MySQL.

Si tiene algún incoveniente por favor verifique los pasos anteriormente mencionados. CABE ACLARAR QUE HAY UN ARCHIVO LLAMADO "Base_de_datos.java" en la carpeta "AgenciaDeViajes" UNA FUNCIÓN LLAMADA "conectar"
LA CUÁL SI USTED CAMBIÓ TANTO EL PUERTO LOCAL Y EL NOMBRE DE LA BASE DE DATOS, DEBERÁ MODIFICAR EL CAMPO LLAMADO "url" Y MODIFICAR EL LOCALHOST Y EL NOMBRE DE LA BASE DE DATOS
